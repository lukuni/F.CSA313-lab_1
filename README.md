## Юу хийсэн

Энэ репозитори нь [https://www.saucedemo.com](https://www.saucedemo.com) сайт дээр Playwright ашиглан 3 функционал тест бичсэн:

1. Амжилттай нэвтрэх → Products хуудас руу шилжсэнийг шалгах → logout
2. Буруу нууц үгээр нэвтрэх → алдааны мессеж гарсныг шалгах
3. Нэвтэрсний дараа бараа сагслах → сагсны тоо нэмэгдсэнийг шалгах → logout

Локатор болгонд `getByRole`, `getByPlaceholder`, `getByText`, `getByTestId` зэрэг орчин үеийн locator ашигласан бөгөөд XPath ашиглаагүй.

## Ажиллуулах заавар

```bash
npm install
npx playwright install
npx playwright test
npx playwright show-report
```

## Trace / нотолгоо

`docs/` хавтсанд:
- `docs/login-fail-trace.zip` — Алхам 4-т заасны дагуу санаатайгаар унагасан тестийн жинхэнэ trace
- `docs/playwright-report/` эсвэл видео файл — амжилттай ажилласан тестийн HTML тайлан

Trace-ийг үзэх:
```bash
npx playwright show-trace docs/login-fail-trace.zip
```
