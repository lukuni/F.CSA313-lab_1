Тестээ бичиж, ажиллуулах явцад надад хамгийн тод санагдсан зүйл бол локатор сонголтын ач холбогдол байлаа. Эхэндээ "Products" гэдэг текстийг getByText ашиглан шалгахад webkit browser дээр өөр элементийн доторх ижил текстэй давхцаж, тест тогтворгүй (flaky) ажиллаж эхэлсэн. Үүнийг шийдэхийн тулд exact: true параметр нэмэх, эсвэл getByRole ашиглах замаар локаторыг илүү тодорхой болгосон нь тестийг тогтвортой болгосон. Энэ туршлага надад "тест унавал юуны түрүүнд хугацаа нэмэх биш, локаторыг сайжруулах хэрэгтэй" гэдгийг ойлгуулсан. Selenium-тэй шууд харьцуулж туршиж үзээгүй тул хоёрын хооронд ялгааг өөрийн туршлагаар харьцуулж чадахгүй байна, гэхдээ Playwright дээр ажиллахдаа browser суулгах (npx playwright install), тест ажиллуулах, HTML тайлан харах гэсэн бүх алхмуудыг нэг л tool-оор, нэг л командын дараалалтайгаар хийж болдог нь надад маш тохиромжтой, цэгцтэй санагдсан. Ялангуяа тусад нь driver татаж суулгах, зам (PATH) тохируулах гэх мэт нэмэлт алхам шаардагдаагүй нь эхлэхэд хялбар байсан.
